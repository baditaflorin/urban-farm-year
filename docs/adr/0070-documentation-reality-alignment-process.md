# 0070 Documentation-Reality Alignment Process

## Status

Accepted

## Context

README claims can drift as implementation changes.

## Decision

README feature claims become a verified checklist. Claims without tests or manual verification are removed or moved to limitations/future work.

## Consequences

The README becomes slightly less promotional and more useful to strangers.

## Alternatives Considered

- Keep aspirational docs: rejected because Phase 3 treats documentation drift as a usability bug.
